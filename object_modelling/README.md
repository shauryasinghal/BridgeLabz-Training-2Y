# Object Modelling Problems

This folder contains Java implementations for various Object Modelling problems (Aggregation, Association, Composition).

## Files
1. `LibraryBooks.java` – Library and Books (Aggregation)
2. `BankCustomer.java` – Bank and Customers (Association)
3. `CompanyDepartments.java` – Company and Departments (Composition)
4. `SchoolStudentsCourses.java` – School and Students with Courses (Association + Aggregation)
5. `UniversityFacultiesDepartments.java` – University with Faculties and Departments (Composition + Aggregation)
6. `HospitalDoctorsPatients.java` – Hospital, Doctors, and Patients (Association + Communication)
7. `ECommercePlatform.java` – E-commerce Platform (Orders, Customers, Products)
8. `UniversityManagementSystem.java` – University Management System (Students, Professors, Courses)
